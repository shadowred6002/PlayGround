## Closet Chaos

A responsive 2D dress-up and slapstick game. Mix tops, bottoms, colors, and accessories for Riley (an adult cartoon character), then use the silly-wedgie button and strength slider to earn style points. Everything runs in the browser with no build step.

Open `index.html` in a browser or serve this folder with any static web server.

## Wedgie Studio 3D

A separate, standalone 3D dress-up game in [`wedgie-studio-3d/`](wedgie-studio-3d/index.html). It keeps the 2D game above untouched and adds an orbiting camera, a procedural 3D character, a full wardrobe with underwear, and eight slapstick wedgie scenarios: classic, frontal, atomic, squeaky, hanging, bouncy, dangling, and chair. Three.js is vendored locally, so it also runs with no build step.
