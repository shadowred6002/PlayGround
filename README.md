## Closet Chaos

A responsive 2D dress-up and slapstick game. Mix tops, bottoms, colors, and accessories for Riley (an adult cartoon character), then use the silly-wedgie button and strength slider to earn style points. Everything runs in the browser with no build step.

Open `index.html` in a browser or serve this folder with any static web server.
